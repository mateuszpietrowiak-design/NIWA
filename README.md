# NIWA — plik wiedzy

To publiczne repozytorium trzyma tylko ogólny plik `agro-wiedza.json`.

Nie wrzucaj tu działek, badań gleby, kosztów, umów ani danych osobowych.

W każdą niedzielę około 19:00 GitHub budzi sprawdzenie źródeł i podmienia plik. Niwa pobiera go przy włączeniu.

Sekret `XAI_API_KEY` ustawia się w Settings → Secrets and variables → Actions. Nie zapisuj klucza w plikach.
